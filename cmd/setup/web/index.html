1. System prüfen

Der Assistent prüft, ob dieser Entwicklungsstand auf deinem Rechner alles Nötige findet.

Schon eingerichtet? Bestehende Installation auf diesem Computer verbinden

Wenn du den Computer gewechselt oder den Installer neu installiert hast, verbindest du hier dein vorhandenes Dashboard. Es werden keine neuen Fly- oder Cloudflare-Ressourcen erstellt.

Das Passwort wird nur für diese Wiederverbindung verwendet und nicht lokal gespeichert.
Keine Entwicklerwerkzeuge nötig. Fly CLI und die Cloudflare-Laufzeit werden bei Bedarf automatisch aus offiziellen Quellen geladen und per SHA-256 geprüft. Der reMarkable-Helfer ist im fertigen Installationspaket enthalten.

Kostenhinweis

Ich verstehe, dass Fly.io ein externer nutzungsbasierter Dienst ist und Kosten verursachen kann.
Der Assistent erstellt genau eine kleine Sync-App und einen 1-GB-Speicher. Cloudflare wird für dieses Projekt im kostenlosen Workers-Setup verwendet. Preise und Bedingungen der Anbieter können sich ändern.
